# Kaji 0.3.0

Kaji 0.3.0 turns the generator into a broader contract-to-developer-tooling
platform: ten SDK languages, generated API CLIs, local mocks, contract checks,
and agent-friendly workflows all come from the same OpenAPI document.

## Highlights

- New Ruby and Swift SDK targets, alongside the canonical C# target and the
  existing TypeScript, Rust, Go, Python, PHP, Java, and Elixir generators.
- Generated TypeScript and Rust API CLIs with nested resource commands, help,
  OAuth support, API-key profiles, and environment-backed credentials.
- `kaji mock serve` for a Docker-free, dynamic local OpenAPI mock server with
  scenario matching, request logs, and health endpoints.
- `kaji check`, `show`, `update`, `discover`, `download`, and `mcp generator`
  for contract review, reproducible generation, API discovery, and agent use.
- Direct-generation locks, path filters, remote authenticated OpenAPI input,
  and runnable examples for the new workflows.

## Quality and compatibility

- `csharp` and `kaji-plugin-csharp` are now canonical; `dotnet` remains a
  compatible alias.
- Generated SDKs are validated from one generated fixture by native Rust,
  TypeScript, Go, Python, PHP, Java, C#, Elixir, Ruby, and Swift checks.
- Fixed generated C#, Ruby, Java, and Elixir compilation issues found by those
  checks.

## Upgrade

```sh
npm install @relevate/kaji@0.3.0
# or
python -m pip install kaji-cli==0.3.0
```
