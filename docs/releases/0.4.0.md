# Kaji 0.4.0

Release notes for Kaji 0.4.0. Package publication is performed by the tagged
release workflow after its verification jobs pass.

## Highlights

- Existing npm manifests are merged during materialization. User scripts,
  metadata, dependency versions, and optional peer classifications survive
  regeneration; missing generated requirements are appended.
- Symfony integration packages wrapping the generated PHP SDK.
- Generated TypeScript and Rust API CLIs now prompt for missing required inputs
  and base URLs in interactive terminals, mask entered credentials, and show
  styled status output. Pipes and `--json` remain non-interactive.
- Generated CLI packages include OpenAPI-derived command reference files under
  `references/<command-group>.md`.
- TypeScript generated headers say “Generated by Kaji” without a website URL.

Kaji does not currently claim a project domain. If a domain is acquired later,
its URL can be added after ownership and availability are verified.

See the [generated SDK guide](https://github.com/rlvtapp/kaji/blob/main/docs/generated-sdks.md) for npm manifest merge
semantics and the [config reference](https://github.com/rlvtapp/kaji/blob/main/docs/config-file.md) for target options.
