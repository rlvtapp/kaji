# Use the Rust SDK

Embed Poolster in a Rust application. Compose input and output plugins, generate
an owned file tree, then decide where to write it.

1. [Quickstart](quickstart.md) — generate a Rust client from OpenAPI.
2. [Compose packages](packages.md) — select plugins and providers.
3. [Check and write](files.md) — handle output safely.
4. [CI, delivery and ejection](automation.md) — automate and customize generation.

This section covers the **Poolster generation SDK**. For calling a generated
Rust GraphQL client, use the [Rust client guide](../reference/outputs/graphql-rust.md).

Want to extend the generator? Use [Rust plugin authoring](../plugins/rust/README.md).
